# Smooth onboarding, moments, and separate statistics consent

Onboarding now changes steps locally with a short animation. Text/typology drafts are account-scoped in versioned localStorage; next/back do not write the profile or navigate. Explicit Save for later / Finish validates and commits all fields together. Avatar files are kept in memory until explicit save; a reload requires selecting the file again. No coordinates are saved: consenting to geolocation calls BigDataCloud directly from the device to resolve country/city. Manual location uses country and city dropdowns sourced from country-state-city 3.2.1 (license included in public/locations/LICENSE). Interests are limited to seven on both client and server; existing selections are preserved until edited.

Profiles display every entered typology and support cover uploads. Personal Moments are separate from Discussion Posts. Owner, accepted friend, public/anonymous, and blocked-viewer access is enforced in both the feed query and media route. The private profile-moments bucket is provisioned on first upload; an existing public bucket is rejected. Signed uploads avoid Vercel request-body limits. Finalization verifies object size, MIME metadata, and file signature. Only finalized uploads owned by the author can be attached. Image files are limited to 10 MB, videos to 50 MB, four files per moment; visibility defaults to private. Read URLs expire after 60 seconds; already issued signed URLs may remain valid until expiry after visibility changes. Unattached uploads remain private and are not exposed by the media route.

Owner-only test history is grouped by month, with numbered attempts and supplied illustrations. Each attempt has its own share/revoke control. Confirmed identities have a separate opt-in with value/source/attempt snapshots. Changing the identity revokes its consent through a database trigger, including changing away then back. The checkbox checks the identity the user saw before opting in. Confirmed-identity statistics are displayed separately and are never added to the existing test-result counts.
